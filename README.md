# Persona Avatar Pool（人设头像库 / 随机头像）

给每个 **persona（用户人设）** 配置一个「头像库」。每次该 user 发言时，从这个 persona 的头像库里**随机抽取一张图片**，作为这一条消息的头像。

相当于给某个 user 的头像加了一个「头像库」功能。

## 功能

- **随机头像**：每次 user 发言，从当前 persona 的头像库里随机抽一张当作这条消息的头像。
- **避免连续重复**：随机时会尽量避开上一条用过的那张。
- **记住每条消息**：抽到的头像写进消息的原生 `force_avatar` 字段，随聊天记录持久化。重新打开聊天，历史消息仍显示当时抽到的那张。
- **不改 persona 真头像**：只改变聊天消息上显示的头像，persona 本身的头像不变。
- **按 persona 绑定**：每个人设各自独立一套头像库。
- **管理弹窗**：在 persona 设置区（`persona_controls_buttons_block`）新增一个按钮，点开后可以：
  - 查看当前 persona 头像库里的所有图片
  - 添加图片（原生上传到酒馆 `User Avatars` 目录）
  - 删除图片
  - 总开关：随时开启/关闭随机头像功能
- **库为空**：不做任何处理，使用 persona 原本的头像。

## 图片存哪里

- 图片本体通过酒馆**原生接口** `/api/avatars/upload` 上传到 **`User Avatars` 目录**（即 persona 头像目录），用原生图片上传（multipart），**不是 base64**。
- 头像库列表只在扩展设置里保存**文件名**，不保存图片本体，所以设置文件不会膨胀。

## 安装

1. 把整个 `persona-avatar-pool` 文件夹复制到酒馆的扩展目录：
   ```
   SillyTavern/data/<你的用户名>/extensions/persona-avatar-pool/
   ```
   （或通过「扩展 → 安装扩展」用本地路径安装。）
2. 重启 / 刷新酒馆。
3. 打开「用户设置 / Persona Management」面板，会在按钮区看到一个新的图片图标按钮（🖼），点击即可管理头像库。

> 本扩展是**纯前端扩展，独立运行，不依赖任何其他插件**。

## 使用

1. 选中你要配置的 persona。
2. 点击 persona 按钮区新增的「头像库」按钮。
3. 点「添加图片」上传若干张图片。
4. 确认「启用随机头像」开关是打开的。
5. 之后用这个 persona 发言时，每条消息都会随机使用库里的一张头像。

## 注意

- 只对**安装插件之后的新发言**生效；安装前已存在的历史消息不会被改动。
- 删除头像时会同时从 `User Avatars` 目录删除该文件。如果某张图正好也被设为某个 persona 的当前头像，请谨慎删除。
- 随机结果写入消息的 `force_avatar` 字段并保存聊天，因此不会因刷新而变化。
